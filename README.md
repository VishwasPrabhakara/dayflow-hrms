# Dayflow - Human Resource Management System

Odoo x NMIT Bangalore Hackathon 2026 virtual round project.

## Problem Statement

Dayflow is a Human Resource Management System focused on digitizing everyday HR workflows:

- Secure sign up and sign in
- Role-based access for Admin/HR and Employee users
- Employee profile management
- Attendance check-in/check-out and attendance records
- Leave and time-off requests
- Admin/HR approval workflows
- Salary and payroll visibility

## Hackathon Execution Plan

The project will be built incrementally with regular commits and pushes.

Initial focus:

1. Project setup and UI foundation
2. Authentication and role-based navigation
3. Employee dashboard and profile screens
4. Attendance check-in/check-out flow
5. Time-off request and approval flow
6. Salary information view
7. Validation, responsive polish, and demo readiness
